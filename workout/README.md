# Тренировки — веб-приложение (PWA)

Бесплатное приложение для силовых и домашних тренировок: готовые программы,
база упражнений с техникой и видео-инструкциями, дневник тренировок, таймеры и статистика.
Работает офлайн, устанавливается на домашний экран iPhone/Android, не требует регистрации и оплат.

**Адрес:** https://piotrgoncharuk.github.io/workout/

## Что внутри

| Раздел | Возможности |
|---|---|
| Тренер | Готовые ответы по ситуации без интернета («завтра игра», «после матча», «20 минут», «устал») с объяснением логики и кнопкой «Начать»; опционально — свободный диалог с Клодом по своему ключу API |
| План недели | Футбол, дни программы, свои заметки и отдых по дням недели; пресеты вроде «Футбол: Чт и Сб»; карточка «Сегодня по плану» на Главной |
| Футбол | Запись тренировок команды, матчей, индивидуальных и вратарских занятий: минуты, тяжесть, голы, передачи, счёт, дистанция; отдельная футбольная статистика |
| Профили | Несколько человек на одном телефоне, у каждого своя история и настройки |
| Нагрузка | sRPE (тяжесть × минуты), сравнение недели со средним за месяц, предупреждение о резком росте объёма |
| Достижения | 18 бейджей: серии, объём, рекорды, голы и передачи |
| Как пользоваться | Пошаговая инструкция, частые вопросы, обозначения; напоминание о резервной копии |
| Главная | Следующая тренировка по программе, цель недели, серия дней, быстрый старт, тоннаж по неделям |
| Программы | 13 готовых планов (зал, дом, сила 5×5, жиросжигание, ягодицы, кор, мобильность), описание прогрессии и расписания |
| Упражнения | 130 упражнений (включая футбольные): техника по шагам, частые ошибки, советы, мышцы, инвентарь, замены, видео |
| Тренировка | Запись подходов (вес × повторы), разминочные подходы, автотаймер отдыха, замена упражнений, заметки, суперсеты |
| Прогресс | Тоннаж и частота по неделям, баланс мышечных групп, личные рекорды, динамика 1ПМ по упражнению |
| История | Календарь-теплокарта, детали каждой тренировки, повтор тренировки одним нажатием |
| Инструменты | Интервальный таймер (Табата / HIIT / EMOM / свой), быстрый отдых, расчёт 1ПМ, калькулятор блинов, разминочные подходы, калории и белок |
| Замеры | Вес и объёмы тела с графиками динамики |
| Настройки | Тема, кг/фунты, звук, вибрация, экран не гаснет, резервная копия всех профилей (JSON), выгрузка истории в CSV |
| Поделиться | Карточка тренировки картинкой через системное меню «Поделиться» |

Данные хранятся только в браузере устройства (localStorage) и никуда не отправляются.
Профили независимы: `fitpro.profiles` хранит список, состояние каждого — в `fitpro.state.<id>`.
Синхронизации между устройствами нет (нужен сервер) — обмен данными идёт файлом резервной копии.

## Установка на iPhone

1. Открыть ссылку в **Safari**.
2. Кнопка «Поделиться» → «На экран «Домой»» → «Добавить».

В приложении это описано в разделе «Ещё → Установить на телефон».

## Видео-инструкции

Кнопки «Видео на русском» / «In English» открывают подборку роликов по конкретному упражнению на YouTube.
Любое видео можно закрепить за упражнением — оно будет проигрываться прямо в карточке:

* в приложении: карточка упражнения → «Своя ссылка» (сохраняется на устройстве);
* для всех пользователей сайта: добавить ссылки в `data/videos.json`:

```json
{
  "bench_press": "https://www.youtube.com/watch?v=ВИДЕО_ID",
  "back_squat": "https://vimeo.com/123456789"
}
```

Ключ — `id` упражнения из `js/data/exercises.js`. Поддерживаются YouTube, Vimeo и прямые ссылки на `.mp4`.
Личная ссылка пользователя всегда имеет приоритет над файлом.

## Структура

```
workout/
├── index.html              оболочка
├── manifest.webmanifest    PWA-манифест
├── sw.js                   service worker (офлайн-кэш)
├── css/app.css             тема и компоненты
├── data/videos.json        общие ссылки на видео (по умолчанию пусто)
├── icons/                  иконки приложения
└── js/
    ├── app.js              маршрутизация и оболочка
    ├── store.js            состояние, localStorage, метрики
    ├── ui.js               DOM-хелперы, шторки, тосты, видео
    ├── charts.js           SVG-графики
    ├── timer.js            таймеры, звук, вибрация, wake lock
    ├── share.js            карточка тренировки картинкой (canvas + Web Share)
    ├── coach.js            встроенный тренер: сценарии и подбор тренировки офлайн
    ├── ai.js               запрос к Claude Messages API прямо из браузера
    ├── data/               база упражнений, программ и футбольного модуля
    └── views/              экраны приложения
```

Сборка не нужна: чистый ES-модульный JavaScript без зависимостей.
Локальный запуск: `python3 -m http.server 8000`, затем открыть `http://localhost:8000/workout/`.

## Обновление версии

При изменении файлов поднимите `VERSION` в `sw.js` (и в `js/app.js`), чтобы у пользователей обновился офлайн-кэш.

## Тренер и Claude API

Кнопки с готовыми вопросами во вкладке «Тренер» работают полностью локально — без сети, ключей и оплаты.

Свободный диалог использует Claude Messages API напрямую из браузера:

* ключ хранится в `localStorage` этого устройства (`fitpro.apikey`) и уходит только на `api.anthropic.com`;
* модель по умолчанию — `claude-opus-5`, в настройках можно выбрать более дешёвую;
* запрос идёт потоком (SSE) с заголовком `anthropic-dangerous-direct-browser-access: true`;
* статическая часть подсказки (правила + каталог упражнений) помечена `cache_control`, поэтому повторные вопросы дешевле;
* в ответе разбирается блок ```` ```workout ```` с идентификаторами упражнений — из него строится карточка с кнопкой «Начать».

Официальный SDK не используется намеренно: приложение собирается без бандлера и должно работать офлайн,
поэтому запрос выполняется через `fetch` в задокументированном формате Messages API.
